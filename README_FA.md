# تسک‌فلو دسکتاپ (TaskFlow Desktop)

یک برنامه ساده دسکتاپ با Python برای مدیریت کارهای روزانه. برنامه در یک پنجره مستقل باز می‌شود و اطلاعات کارها را در فایل JSON روی کامپیوتر ذخیره می‌کند.

## امکانات

- افزودن کار جدید
- مشاهده فهرست کارها
- علامت‌گذاری کار به‌عنوان انجام‌شده
- حذف کار انتخاب‌شده
- ذخیره خودکار کارها در `data/tasks.json`
- بازیابی کارها هنگام اجرای مجدد برنامه

## پیش‌نیازها

- Python نسخه 3.10 یا جدیدتر
- Tkinter (معمولاً همراه نصب استاندارد Python در ویندوز موجود است)

این پروژه به نصب کتابخانه جانبی نیاز ندارد.

## اجرای برنامه

ترمینال را در پوشه اصلی پروژه باز کن و اجرا کن:

```bash
python -m taskflow.main
```

## اجرای تست‌ها

```bash
python -m unittest discover -v
```
